# drying-cabinet

Parametric fan duct / filter housing (build123d), for a clean-air cabinet used for airbrushing.

## Material

PETG (not PETG-CF). Many thin features here (2mm finger-guard bars, support
ribs, snap-fit walls) benefit more from PETG's toughness than PETG-CF's
stiffness; CF tends to make thin sections brittle and wears nozzles unless
running hardened steel. PETG's chemical resistance already covers airbrush
solvent/paint fumes, and nothing here is structurally loaded enough to need
CF's rigidity.
